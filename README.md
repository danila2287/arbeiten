# arbeiten — сайт аренды мебели для небольших мероприятий

Многостраничный статический сайт на Vite. У каждой категории и каждого товара —
своя HTML-страница с заголовком, описанием и разметкой для Яндекса. Интерактив
(заявка, поиск, наборы) добавляет небольшой JavaScript поверх готового HTML.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # готовый сайт в папке dist/ — её и выкладываете на хостинг
npm run preview  # посмотреть собранную версию
```

## Как это устроено

Страницы генерирует `scripts/generate.mjs` из каталога и шаблонов. Он запускается
сам при `npm run dev` и `npm run build`, а в режиме разработки пересобирает
страницы, когда вы сохраняете каталог, контакты или шаблоны.

Сгенерированные файлы — `index.html`, `catalog/`, `item/`, `cart/`, `delivery/`,
`contacts/`, `404.html`, `public/sitemap.xml`, `public/robots.txt` — **не правьте
руками** и не коммитьте (они в `.gitignore`): при следующем запуске они перезапишутся.

## Где что менять

| Что | Файл |
|---|---|
| Название, адрес сайта, телефон, мессенджеры, Авито, Метрика, доставка | `src/config.js` |
| Категории, их заголовки и тексты для поиска | `src/data/catalog.js` → `categories` |
| Товары, цены, остатки, готовые наборы | `src/data/catalog.js` → `products`, `kits` |
| Фото товаров | положить в `public/images/`, в товаре добавить `image: '/images/файл.jpg'` |
| Разметка страниц | `src/templates/pages.js`, шапка и подвал — `src/templates/layout.js` |
| Интерактив в браузере | `src/main.js`, страница заявки — `src/client/cart-page.js` |
| Расчёт стоимости за несколько дней | `src/lib/cart.js` → `dayFactor` |
| Текст заявки, отправка на сервер | `src/lib/order.js` |
| Стили | `src/styles.css` |

## Перед публикацией

1. В `src/config.js` укажите реальный адрес сайта в `url` — от него строятся
   canonical-ссылки и `sitemap.xml`.
2. Заведите счётчик в Яндекс.Метрике и впишите его номер в `metrikaId`.
3. Добавьте сайт в Яндекс.Вебмастер и отправьте туда `https://ваш-сайт/sitemap.xml`.

## Хостинг

Подойдёт любой статический хостинг: Netlify, Vercel, Cloudflare Pages, обычный
хостинг с загрузкой папки `dist/`. Адреса вида `/catalog/chairs/` работают без
настройки сервера. Для GitHub Pages без своего домена (адрес `…github.io/arbeiten/`)
понадобится настройка `base` в `vite.config.js` — проще сразу подключить свой домен.
