# arbeiten — сайт аренды мебели для небольших мероприятий

Vite + чистый JavaScript (ES-модули), без фреймворков. Каталог, карточки товаров,
готовые наборы, заявка с расчётом суммы и отправкой в WhatsApp / Telegram.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # готовый сайт в папке dist/
npm run preview  # посмотреть собранную версию
```

## Где что менять

| Что | Файл |
|---|---|
| Название, телефон, мессенджеры, Авито, минимальный заказ, доставка | `src/config.js` |
| Категории, товары, цены, остатки, готовые наборы | `src/data/catalog.js` |
| Фото товаров | положить в `public/images/`, в товаре добавить `image: '/images/файл.jpg'` |
| Расчёт стоимости за несколько дней | `src/lib/cart.js` → `dayFactor` |
| Текст заявки и отправка на сервер | `src/lib/order.js` |
| Стили | `src/styles.css` |

## Структура

```
src/
  main.js            роутинг (#/catalog, #/item/:id, #/cart …)
  config.js          контакты и условия
  data/catalog.js    товары
  lib/               корзина, заявка, мелкие помощники
  components/        шапка, подвал, карточка товара, иллюстрации
  pages/             страницы
```

Роутинг хешевый (`/#/catalog`), поэтому сайт работает на любом статическом
хостинге — GitHub Pages, Netlify, Vercel, обычный хостинг — без настройки сервера.
